Informasi

Selamat datang di sistem informasi data mahasiswa praktikum pemrograman web kelas E. Sistem ini digunakan untuk mengelola data mahasiswa, termasuk menambahkan, mengedit, dan menghapus data mahasiswa.

Fitur Sistem

Sistem ini memiliki beberapa fitur utama:

  • Menampilkan daftar mahasiswa
  • Menambahkan data mahasiswa baru
  • Mengedit data mahasiswa yang sudah ada
  • Menghapus data mahasiswa
